# 🧠 智绘工坊 · AI 思维导图与图表

> 一句话 / 一个知识点 → 自动生成**可拖拽、可折叠的思维导图**，或**柱状图 / 折线图 / 饼图 / 散点图 / 流程图**，支持 2D/3D 切换，一键**导出为图片 / Word / PDF**。

**智绘工坊** 是一个开箱即用的本地 AI 应用：打开就是输入框，输入「勾股定理」或一段教材文字，点「生成导图」，AI 自动把内容拆成层级清晰的思维导图；想要图表，切到「其它图表」页，描述几句就生成漂亮的数据图表。适合**学习、备课、知识整理、数据可视化**。

## 🚀 快速开始

### 方式 A：桌面版（推荐，无需 Python）

1. 解压 `智绘工坊_桌面版_v1.0.zip`，双击里面的 **`智绘工坊.exe`**
2. 首次运行自动在**桌面创建快捷方式**「智绘工坊」
3. 右上角 😀 → 个人中心 → 填 API Key → 开始使用

### 方式 B：浏览器版（源码运行）

需要 Python 3.11+，零第三方依赖：

```bash
python server.py
```

浏览器自动打开 http://localhost:8000/ ，输入知识点点「生成导图」即可。

### 方式 C：命令行模式（可选）

```bash
python mindmap.py "勾股定理"
python mindmap.py "讲讲二分查找" -o 二分查找.html
echo "一段教材文字..." | python mindmap.py -o 教材.html
```

## 📖 使用教程

### 1. 配置模型（首次必做）

打开应用 → 右上角 😀 **个人中心** → 选服务商 → 选模型 → 填 API Key → 保存。

**推荐配置**：服务商选「智谱 GLM」，模型选 `glm-4-flash`（永久免费），或 `glm-4.7-flash`。

> 也可以编辑项目里的 `.env` 文件（复制 `.env.example` 为 `.env` 后填写）。

### 2. 生成思维导图

- 在输入框输入知识点，如 `勾股定理`、`C语言指针`、`太阳系八大行星`
- 点「生成导图」，或点下面的示例词一键生成
- 右侧可切换 **⚡快速 / 标准 / 详细**（影响导图的丰富程度）

### 3. 操作思维导图

| 操作 | 方式 |
|---|---|
| 平移 | 拖拽空白处 |
| 缩放 | 滚轮 |
| 折叠/展开节点 | 点击节点 |
| 展开全部 / 折叠全部 | 工具栏 ⤢ / ⤡ |
| 放大 / 缩小 / 适应窗口 | 工具栏 ＋ / － / ⌂ |
| 导出图片 / Word / PDF | 工具栏 🖼️ / 📄 / 📕 |

### 4. AI 助手优化导图

生成导图后，点右下角 **🤖** → 输入改进意见，如：

```
结构太乱了，整理一下
补充更多应用场景
内容太少，再展开详细一点
```

AI 会给出改进建议 + 优化后的新导图，点「应用建议并重新生成」即可。

### 5. 学习助手（含拍照解题）

AI 助手面板 → 切到「学习助手」Tab：

- **问问题**：输入题目/知识点，如 `勾股定理怎么证明？`
- **拍照解题**：点「📷 上传题目照片」，上传题目照片，AI 识别并给出详细解答

### 6. 生成其它图表

切到顶部「📊 其它图表」页：

- 选类型按钮：**🤖自动 / 🍩饼图 / 📈折线 / 📊柱状 / ✨散点 / 🔀流程**
- 输入描述，点「生成图表」
- 生成后点「2D/3D」切换立体视角，鼠标拖动旋转
- 支持**多轮修改**：生成后在对话输入框继续提要求，如 `把标题改成...`、`加一条折线系列`、`换成柱状图`
- 右侧可**下载配置**、**导出图片/Word/PDF**

## 📦 安装指引（Windows 桌面版）

**安装步骤：**

1. 解压 `智绘工坊_桌面版_v1.0.zip` 到任意文件夹（建议 `D:\智绘工坊\`）
2. 双击 `智绘工坊.exe` 即可使用

**首次运行自动完成：**
- 桌面创建快捷方式「智绘工坊」✓
- 生成 `config.json`（模型配置）、`history.json`（历史）、`app.log`（日志）

**常见问题 FAQ：**

| 问题 | 解决 |
|---|---|
| 双击没反应？ | 右键 exe → 属性 → 勾选「解除锁定」→ 确定 |
| 报"API Key 无效"？ | 右上角 😀 个人中心重新填写正确的 API Key |
| 生成时提示"未配置"？ | 个人中心配置主模型；AI 助手可单独配置 |
| 想换位置？ | 整个文件夹搬走即可，配置跟着 exe 走 |
| 怎么卸载？ | 删 exe 和文件夹 + 桌面快捷方式，无残留 |

## 🏗️ 技术架构

```
┌─────────────────────────────────────────────────┐
│  桌面窗口 (PyWebview / WebView2)                │
│  ┌───────────────────────────────────────────┐ │
│  │  index.html（单文件前端）                  │ │
│  │  markmap · ECharts · ECharts-GL ·        │ │
│  │  Mermaid · KaTeX（全部本地化离线）          │ │
│  └───────────────────────────────────────────┘ │
│          ↕ HTTP (localhost:8000)                │
│  ┌───────────────────────────────────────────┐ │
│  │  server.py（Python 标准库 HTTP 服务器）    │ │
│  │  /api/generate  生成导图                   │ │
│  │  /api/improve   AI 助手优化               │ │
│  │  /api/learn     学习助手（文字+拍照）       │ │
│  │  /api/chart     图表（2D/3D）             │ │
│  │  /api/config    配置读写                  │ │
│  │  /api/history   历史读写                  │ │
│  └───────────────────────────────────────────┘ │
│          ↕ OpenAI 兼容接口                      │
│  智谱 · DeepSeek · Kimi · Qwen · Ollama ...    │
└─────────────────────────────────────────────────┘
```

**技术要点：**
- 后端**零第三方依赖**（Python 标准库），轻量可靠
- 前端渲染库**全部本地化**（markmap/ECharts/KaTeX/Mermaid），完全离线可用
- 模型走 **OpenAI 兼容接口**，国内直连免翻墙
- 支持 8 家服务商，网页里切换即可，无需改代码

## 🗂️ 数据存储

| 文件 | 作用 |
|---|---|
| `config.json` | 模型配置（服务商/模型/API Key），个人中心保存 |

## 🔓 开源与隐私

本仓库已配置 `.gitignore` 排除隐私文件，上传 GitHub 时**以下文件绝不提交**：

| 文件 | 原因 |
|---|---|
| `config.json` / `.env` | 含你的 API Key |
| `history.json` | 你的生成历史数据 |
| `dist/` `build/` | 打包产物 |
| `app.log` | 运行日志 |

```bash
pip install pyinstaller pywebview
```
